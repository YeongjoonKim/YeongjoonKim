## Selected Engineering Work

1. [Reliable Domain Agent Harness](https://github.com/YeongjoonKim/reliable-domain-agent-harness)
   — explicit runtime, evidence/claim/span verification, bounded recovery, Docker scientific
   execution, configuration/evidence replay and a minimal MCP stdio implementation.
2. [Efficient Fine-tuning Lab](https://github.com/YeongjoonKim/efficient-finetuning-lab)
   — actual QLoRA training and adapter serving evidence, plus separate reproducible CPU experiments.
3. [Multimodal Domain AI](https://github.com/YeongjoonKim/multimodal-domain-ai)
   — vision as an uncertain tool, taxonomy/evidence integration and an observed failure case.
4. [AI Domain Intelligence Reporting](https://github.com/YeongjoonKim/ai-domain-intelligence-reporting)
   — source provenance, extraction/refinement, human validation and evidence-linked reporting.

These recently published repositories are publication-safe evidence packages and independent
reference implementations derived from existing engineering work. Private production source,
data and infrastructure are not mirrored here. Actual experience, public reference code and
lightweight synthetic demos are distinguished; synthetic results are not production benchmarks.
